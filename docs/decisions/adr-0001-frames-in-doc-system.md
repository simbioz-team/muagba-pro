# ADR-0001. Документы рамок живут в системе документации

- **Дата:** 2026-09-19
- **Статус:** принято

## Контекст

Документы рамок — конституция, миссия, словарь, тех.стек, раскладка — были
обычными markdown-файлами вне какой-либо системы. Из-за этого:

- заполненность проверял только `check-frames.py`: он видит пустые слоты, но не
  видит, осмысленно ли написанное;
- не было механизма «какие разделы заполнить» — человеку подсовывался пустой
  шаблон без вопросов;
- документы не попадали в реестры, то есть агент находил их только если путь
  был прописан в своде правил.

При этом весь недостающий аппарат уже построен в `docsys`: шаблоны типов,
`/doc-new` с интервью по разделам, `/doc-audit` на качество содержания, пять
проверок.

## Решение

Документы рамок — документы системы документации. У них есть frontmatter, они
попадают в `INDEX.md` и `TAGS.md`, к ним применяются все команды и проверки
`docsys`.

`docsys` становится плагином **класса А**: без него гейты Э2–Э4 не закрываются.

## Альтернативы

**Оставить как есть и построить механизм внутри `muagba-base`.** Отклонено:
пришлось бы второй раз написать шаблоны, интервью и проверку качества, а потом
поддерживать две расходящиеся реализации одного и того же.

**Поднять только продуктовые документы** (миссия, карта, словарь), оставив
конституцию и определение готовности простыми файлами. Довод был в том, что их
читают из свода правил каждую сессию и frontmatter там лишний. Отклонено:
качество конституции проверять нужно не меньше, а разделение породило бы два
правила вместо одного.

## Последствия

Проще: «какие разделы» и «заполнено правильно» закрываются тем, что уже
построено. Документы рамок находятся поиском по реестру.

Сложнее: `muagba-pro` получает зависимость от `docsys`. Раньше база была
самодостаточной.

Требуется от `docsys`: поддержка `templates_dir` в конфиге — шаблоны рамок
принадлежат проекту, а не плагину.

Разделение ответственности: в `docsys` всё общее — поля, реестры,
плейсхолдеры, качество. В `muagba-pro` — только знание о своих документах:
что в миссии обязан быть непустой раздел антицелей, что у каждого принципа
конституции есть пометка способа исполнения. Это знание предметное, в
универсальную систему документации ему нельзя.
