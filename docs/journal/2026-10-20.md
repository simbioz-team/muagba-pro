## Что сделано

- `gate_key.py`: отпечаток — хеш дерева рабочих файлов (`git write-tree`
  во временном индексе, копия настоящего), без HEAD. Команды `changed`
  (пути между двумя деревьями) и `waiting` (живые фоновые задачи агента).
- `gate-check.sh`: общий список зелёных в git-common-dir
  (`muagba-gate-green`: «дерево событие время»), последнее зелёное дерева —
  `git-path muagba-gate-last`. SubagentStop засчитывает только своё, Stop —
  своё и SubagentStop. Передаёт `MUAGBA_GATE_BASE` / `MUAGBA_GATE_CHANGED`.
  Остановка с живыми своими фоновыми задачами — `decision=deferred`.
  В журнал `decision=pass` и `duration_ms` у всех прогонов.

## Проверено

- Claude Code 2.1.304, headless-проба с хуком-дампом: во входе Stop и
  SubagentStop есть `background_tasks` (id, type, status…) и

- Возврат к ранее зелёному дереву после красного — теперь кэш (было:
  красный стирал отпечаток). Следствие содержимого как ключа; тест поменять.
- Короткий набор docs/specs в каркасе — только если проект завёл цель
  `check-docs`: без неё пропуск check-quick снял бы, например, линт markdown.

- Тесты run.sh под новый гейт: кэш между деревьями, коммит без правок,
  deferred, CHANGED/BASE, pass+duration; каркас check.sh (короткий набор).
- Каркас check.sh: `gate_touches`/`gate_only`, `check-docs`, заметка о
  портах; В6.9 «Заодно спроси»; ADR-0018; README; CHANGELOG 0.21.1 (патч:
  гейтов не добавлено); template_sync --build.
- day/night: обёртка каркаса `.claude/night-switch` (синхронизируется,
  защищена), разрешение `Bash(./.claude/night-switch *)` в settings.json
  каркаса и `allowed-tools` скилов; скилы запускают её сами, строка `!` —
  запасной путь. Дополнение к ADR-0016.

## Проверено (2)

  на входе в auto сбрасываются широкие правила с интерпретатором
