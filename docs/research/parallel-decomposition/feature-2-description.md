# Фича 2. Теория ступени по нуждам задач и пометка «теория отстала» (шаг 8 пайплайна создания курса)

Проект: «Наставник» (`/home/rustam/develop/simbioz_team/nastavnik_stage_1`) — платформа создания
курсов. Курс состоит из компетенций, линий и ступеней (`TaskClass`); у ступени есть целевые умения
(KSA) и задачи; ученик проходит ступень уроком А (теория) и уроком Б (практика). Пайплайн создания
курса переделывается по концепции 17–18.11 шагами; новое — только на курсах с флагом
`Course.pipeline_v2`, курсы без флага — «старый путь».

## Цель

На курсе с флагом теория становится частью ступени, а не отдельной ступенью-«чтением» в теме.
У ступени три вида материала: **теория** (урок А: поддерживающие знания, впервые нужные на этой
ступени, по пяти шагам понимания), **карта подхода** (раздел теории — план действий ступени) и
**подложка** (как сейчас — контекст урока Б). Состав теории считается из графа курса, целевых умений
ступени и её задач. Если задачи добавили потребность, которой в теории нет, автор видит «теория
отстала» и одной кнопкой дописывает только недостающее. У материала свой курс: через него работают
доступ, редактор, версии, разделы, вставные вопросы и проверка покрытия; тема остаётся ярлыком и
материалу не нужна. Существующая «Теория» курсов переносится на ступени командой без вызовов модели.

## Требования (сжато; полный текст — санированная спека, §5)

**Носитель и хранение.**
- R-1: на флаге «Теория» больше не класс задач темы; R-2: поле `TopicContent.carrier_purpose`
  (`theory` | NULL) с инвариантами; R-3: тема материалу не нужна (`topic = NULL` на флаге);
  R-4: карта подхода — ровно один раздел на ступень.

**Состав теории.**
- R-5: одна чистая функция состава — новый модуль `courses/rung_theory/needs.py`; R-6: нужда — по
  целевым умениям и задачам ступени, состав — по первой ступени в порядке курса, знания точки входа
  не входят, процедурные (jit) — в урок Б; R-7: «раньше» — только порядок курса; R-8: снимок состава
  на каждой версии носителя, записанной генерацией.

**Пометки и строки «Контента».** R-9 «теория отстала», R-10 «лишнее», R-11 «новой теории нет»,
R-12 «теория не сгенерирована».

**Генерация и деньги.**
- R-13: «Сгенерировать теорию», «Дописать теорию» (черновик: прежние разделы + недостающее),
  «Сгенерировать карту» — существующая ручка генерации, режимы `generate`/`complete`/`map`;
- R-14: деньги — по канону учёта, без нажатия автора ничего не тратится, резерв ≥ факт;
- R-15: промпт теории ступени в сервисе `ml-llm` (`kind=rung_theory`, шаг 4 — полями question/rule);
- R-16: перегенерация структуры — теория уходит со ступенью по ключу; R-17: удаление ступени с
  утверждённой теорией паркует ступень; R-17a: писатели `TaskClass` — только через `course_structure`.

**Уроки и трек.** R-18 урок А на флаге — по ступени; R-19 ссылки «Опирается на» и чтение теории
ступени учеником (право по доступу к курсу, без зачёта); R-20 урок Б, контекст генерации задач и
банк диагностики берут знания из теории нужных ступеней и карту ступени.

**Материал ступени: курс, доступ, адреса, писатели.** R-28 `TopicContent.course`; R-29 доступ к
материалу без темы; R-30 ручки материала ступени — адреса с курсом (только флаг); R-31 ручки по
теме на флаге отказывают 422 `/problems/course-path-not-applicable`; R-32 все писатели материала на
флаге пишут `topic = NULL`; R-33 редактор материала (`ContentEditorDrawer`) работает с материалом
ступени; R-34 новый код «действие не для этого пути».

**Перенос существующей теории.** R-21: management command `migrate_rung_theory` — идемпотентная,
`--dry-run` по умолчанию, без вызовов модели, переносит «Теорию» линии на первую ступень пары,
удаляет пустые оболочки, пишет журнал изменений; обратимость и предполётная проверка.

**Гейты.** R-22 новые правила гейта 2 на флаге (знание без раздела — блокер, раздел без знаний —
предупреждение, «отстала» — предупреждение, нет карты — блокер); R-23 что снимается с флага и откат
гейта 2 только при снятии покрытия знания; R-24 выведение `reading-material-outdated`.

**«Контент» и окно ступени.** R-25 ручка чтения `GET /api/v1/courses/{course_id}/rung-theory`;
R-26 вкладка «Контент» на флаге сгруппирована по ступеням; R-27 окно ступени на флаге без поля
«Тип», без кнопки «+ Теория».
