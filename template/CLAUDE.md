# Специфика Claude Code

Основной свод правил — в `AGENTS.md` выше. Здесь только то, что касается
Claude Code.

## Роли

Приходят с плагином `muagba-base`:

- `implementer` — одна задача в изолированном рабочем дереве, до зелёной проверки
- `reviewer` — свежий взгляд на дифф, только доклад, ничего не правит
- `researcher` — исследование в отдельном контексте, возвращает выжимку

## Параллельная работа

- Изоляция: `claude --worktree <имя>` либо `isolation: worktree` у роли.
- Дерево — свежий checkout: то, что ему нужно из gitignored, перечислено
  в `.worktreeinclude`.
- Сабагент не наследует разговор. Всё, о чём договорились в чате, для него
  не существует — договорённость должна лежать в файле.

## Принудительные рамки

- `.claude/settings.json` — права и хуки
- `.claude/protected-paths.txt` — что нельзя править
- `.claude/invariants.md` — что возвращается в контекст после компакции
- `docs/journal/` — журнал сессии: хук напоминает его вести и возвращает
  после компакции
- `.claude/check.sh` — гейт завершения хода
