# Правила для тестов

- Тест проверяет поведение, а не реализацию: переписанная внутренность не
  должна ронять тест.
- Один тест — один смысл. Имя говорит, что именно сломается.
- Эталонные значения, посчитанные человеком, менять нельзя. Если код даёт
  другое — неверен код.
- Не подгонять тест под текущее поведение, чтобы он позеленел.
