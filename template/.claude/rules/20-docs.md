# Документы

Каждый документ в `docs/` начинается с frontmatter:

```yaml
---
title: <название>
scope: product          # product | meta
type: <тип>
tier: foundation        # foundation | feature | feature-derived (где применимо)
status: draft           # active | draft | deprecated | superseded | archived
updated: ГГГГ-ММ-ДД
tags: [<3-6 тегов>]
summary: <1-3 предложения: что внутри и что зафиксировано>
---
```

Правила:

- **Не выдумывать отсутствующие поля.** Нет значения — нет поля; в реестре будет
  прочерк. Реестр обязан отражать источник, а не догадку о нём.
- `summary` — содержание, а не тема: по нему решают, открывать файл или нет.
- `status: active` означает «на это можно опираться». Повышает человек, не агент.
- Если в теле есть раздел `## Status`, его значение обязано совпадать с frontmatter.
- `docs/INDEX.md` и `docs/TAGS.md` — **сборка, не документы.** Руками не править.

Навигация: `INDEX.md` → нужный документ. Поиск — по `TAGS.md`, не чтением всех
файлов подряд.
