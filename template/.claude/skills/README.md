# Скилы этого проекта

Сюда — процедуры, которые повторяются в этом проекте и не нужны другим.
Общие (`setup-project`, `new-feature`, `write-adr`) приходят с плагином.

Признак, что пора завести скил: третий раз вставляешь в чат один и тот же
плейбук.

```
.claude/skills/<имя>/SKILL.md
```

```markdown
---
name: <имя>
description: <что делает и когда применять>
disable-model-invocation: true   # для процедур с побочными эффектами
---
<шаги>
```
