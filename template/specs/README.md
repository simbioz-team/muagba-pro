# Артефакты задач

Одна фича — одна директория `NNN-<slug>/` с тремя файлами:

- `spec.md` — что и зачем, требования в проверяемой форме, что вне рамок
- `plan.md` — как, плюс обязательная сверка с конституцией
- `tasks.md` — нарезка на задачи по 2–5 минут с проверяемым результатом

`tasks.md` — нарезка одной фичи, а не доска. Как доска он работает ровно для
**одного агента за раз**: у каждого рабочего дерева свой checkout, поэтому
незакоммиченная отметка «взял» в соседнее дерево не попадает вовсе, а
закоммиченная остаётся в своей ветке. Сосед её не увидит.

Для параллельной работы общее состояние задач живёт вне рабочего дерева:
встроенный общий список Claude Code, MCP-сервер трекера или issues. Где
именно — записывается в `docs/workflow.md`, раздел «Где живут задачи», и
проверяется пробой `roles.board`. Почему так — `ADR-0008` базы.

Заводится скилом `/muagba-base:new-feature`.
