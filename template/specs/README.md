# Артефакты задач

Одна фича — одна директория `NNN-<slug>/` с тремя файлами:

- `spec.md` — что и зачем, требования в проверяемой форме, что вне рамок
- `plan.md` — как, плюс обязательная сверка с конституцией
- `tasks.md` — нарезка на задачи по 2–5 минут с проверяемым результатом

`tasks.md` работает как доска для параллельных агентов. Сабагенты не делят
контекст — только файлы: агент берёт задачу, отмечает её, следующий видит
актуальное состояние.

Заводится скилом `/muagba-base:new-feature`.
