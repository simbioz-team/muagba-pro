# Артефакты задач

Одна фича — одна директория `NNN-<slug>/` с тремя файлами:

- `spec.md` — что и зачем, требования в проверяемой форме, что вне рамок
- `plan.md` — как, плюс обязательная сверка с конституцией
- `tasks.md` — нарезка на задачи по 2–5 минут с проверяемым результатом

`tasks.md` — нарезка одной фичи, а не доска. Как доска он работает ровно для
**одного агента за раз**: у каждого рабочего дерева свой checkout, поэтому
незакоммиченная отметка «взял» в соседнее дерево не попадает вовсе, а
закоммиченная остаётся в своей ветке. Сосед её не увидит.

Для параллельной работы общее состояние задач живёт вне рабочего дерева:
встроенный общий список Claude Code, MCP-сервер трекера или issues. Где
именно — записывается в `docs/workflow.md`, раздел «Где живут задачи», и
проверяется пробой `roles.board`. Почему так — `ADR-0008` базы.

Заводится скилом `/muagba-base:new-feature`.

## Форма

Её проверяет `check_specs.py` из базы, вызываемый из `.claude/check.sh`.
Форма, которую ничего не проверяет, не держится даже у того, кто её придумал:
в проекте, где такую проверку завели, она сразу нашла 23 расхождения в
спеках, написанных часом раньше.

**`spec.md`**

```
- **status:** draft
```

`draft` — форму проверяем, готовность нет. `active` — проверяем и готовность:
ни одной живой пометки `[ТРЕБУЕТ УТОЧНЕНИЯ` вне раздела «Решения по
умолчанию», и каждое требование покрыто задачей. Статус `active` ставит
человек.

Требования нумеруются и несут способ проверки:

```
- R1. КОГДА <условие> СИСТЕМА ДОЛЖНА <поведение>
  Проверка: <чем именно это проверяется>
```

**`plan.md`** — раздел `## Сверка с конституцией` таблицей, где названы все
принципы проекта (список читается из вашей конституции, не зашит в базу). При
наличии хранилища — ещё `## Расхождения со схемой`.

**`tasks.md`** — задача ссылается на требования и перечисляет файлы:

```
- [ ] T001 <действие> → <проверяемый результат>   [R1, R2]
  Файлы: путь, путь
```

`[R—]` — для задач, не закрывающих требование (подготовка, уборка). Отметка о
выполнении несёт, кто и когда: `- [x] T001 … (implementer, 2026-09-21)`.
Список файлов — то, по чему определяется пересечение задач.
