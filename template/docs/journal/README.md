# Журнал сессий

`CHANGELOG` отвечает, что изменилось; `docs/decisions/` — почему так решили.
Здесь — третье: как шла работа, где она сворачивала не туда и чем это ловили.
Именно это теряется при сжатии контекста и переоткрывается заново через месяц.

**Каталог включает хук.** Пока `docs/journal/` существует, плагин
`muagba-base`:

- напоминает агенту обновить журнал, когда контекст вырос на
  `MUAGBA_JOURNAL_EVERY` токенов (по умолчанию 150 000) с последней записи;
- сохраняет выжимку, которую Claude Code делает при сжатии, в
  `.claude/logs/compact/` — страховка на случай, если агент журнал не
  дописал;
- после сжатия возвращает агенту путь к последней записи и велит перечитать
  её и продолжить.

Удалите каталог — хук замолчит.

## Правило записи

<!-- no-question: правило, а не слот: журнал копится по ходу работы -->

Файл на сессию, имя — дата последнего дня: `ГГГГ-ММ-ДД.md`. Одна сессия —
один файл, его и дописывают.

**Ошибки описывать полнее, чем успехи.** Успех восстанавливается по коду,
ошибка — нет.

<!-- Разделы ниже — скелет записи. Переименуйте под проект, но держите
     «Следующий шаг»: после сжатия агент продолжает именно с него. -->

- **С чего началась** — задача словами человека, дословно важное.
- **Что сделано** — коротко, со ссылками на коммиты и документы.
- **Где ошибался** — что утверждал, не проверив; какая проверка ничего не
  проверяла; чем поймано.
- **Решения, которые стоит помнить** — и почему.
- **Что открыто** — с причиной, почему не закрыто.
- **Следующий шаг** — одна строка, с чего продолжать.

## Ночной прогон

<!-- no-question: справка по настройке окна, заполнять нечего -->

Сжатие запускает сам Claude Code, когда контекст подходит к окну; агент
вызвать `/compact` не может. Окно задаётся при настройке окружения
(В10.5): `.claude/settings.json` → `autoCompactWindow`, в каркасе —
300 000. Без него окно выбирает Claude Code по модели, и оно меняется без
предупреждения.

На время одного прогона окно можно сменить переменной — она сильнее
настройки:

```bash
CLAUDE_CODE_AUTO_COMPACT_WINDOW=200000 claude ...
```

Порог напоминания держите не больше половины окна: иначе сжатие придёт
раньше напоминания. Это сверяет проба `observe.compact`.

Механизм стоит хоть раз проверить на малом окне (200 000): напоминание,
выжимка, возврат журнала после сжатия.

## Выжимки сжатия

<!-- no-question: пишется хуком, не заполняется при настройке -->

Лежат в `.claude/logs/compact/`, а не здесь: это сырьё без frontmatter, и
система документации роняла бы на нём свой гейт. Каталог в `.gitignore`.
Важное из выжимки агент переносит в запись сессии.

## Стенограммы

<!-- no-question: справка, заполнять нечего -->

Журнал — то, что агент записал сам. След того, что он на самом деле читал
и что было в его задании, — в стенограммах сессий Claude Code. Они
удаляются через `cleanupPeriodDays` дней (по умолчанию 30). Собираетесь
разбирать ход работы позже — поднимите срок в `.claude/settings.local.json`.
Рассуждения модели в стенограммах бывают пусты: «почему» по ним не
восстановить, а «что прочитал» — можно.

## Система документации

<!-- no-question: настраивается на Э1, здесь справка -->

Записи журнала — не документы системы документации: frontmatter у них нет.
В `.claude/doc-config.json` путь исключён: `"exclude": [..., "docs/journal/**"]`.
Проба `observe.journal` это сверяет.
