## Как читать

Агент берёт файл этапа, отбрасывает вопросы, чьё `Спрашивать:` не выполняется,
и по каждому оставшемуся сначала ищет ответ в `docs/sources/` — если там
что-то есть. Найденное показывает на подтверждение, ненайденное спрашивает.

**Ответ не записывается сразу.** Сначала сверяется с полем `Плохой ответ`; если
подходит под описанный там провал, агент говорит, чем именно ответ плох, и
спрашивает снова. Один повтор, дальше записывает как есть и помечает раздел
для `/doc-audit`.

складываются.
