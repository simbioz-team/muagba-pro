# Э1. Точка входа для агентов — вопросы

Свод правил наполняется по мере проекта, поэтому вопросов немного: нужен
адрес, минимальный каркас и то, что известно про грабли заранее.

Последний вопрос — про импорт. Он задаётся **в конце этапа**, когда `docsys`
уже развёрнут и материалу есть куда лечь.

### В1.1 Какими агентскими инструментами пользуются в проекте, кроме Claude Code

**Заполняет:** решение З1.1 — `AGENTS.md` либо `CLAUDE.md`
**Спрашивать:** всегда
**Зачем:** при наличии обоих файлов Claude Code читает только `CLAUDE.md`,
если тот не импортирует второй. Инструменты других вендоров читают `AGENTS.md`.
Раскладка выбирается один раз: переезд позже означает вычитку двух
разошедшихся файлов.
**Плохой ответ:** «пока только Claude Code, потом посмотрим». Если есть хоть
малейший шанс на второй инструмент, дешевле сразу `AGENTS.md` плюс
однострочный `CLAUDE.md` с импортом.
**Источник:** задача З1.1.

### В1.2 Какие команды набираются в этом проекте чаще всего

**Заполняет:** свод правил → раздел «Команды»
**Спрашивать:** всегда
**Зачем:** агент не наследует разговор и не угадывает, чем собирают проект.
Раздел команд — самая используемая часть свода.
**Плохой ответ:** выгрузка всех скриптов из манифеста. Нужны те пять, которые
набирают руками; остальные найдутся в манифесте.
**Источник:** задача З1.2.

### В1.3 Что агент делал неправильно в похожих ваших проектах

**Заполняет:** свод правил → раздел «Чего не делать»
**Спрашивать:** всегда
**Зачем:** свод наполняется по мере появления ошибок, но часть их известна до
начала. Записать заранее дешевле, чем поймать.
**Плохой ответ:** общие места вроде «не писать плохой код». Правило работает,
когда называет конкретное действие: «не переписывать соседний модуль заодно».
**Источник:** задача З1.2.

### В1.4 Есть ли правила, которые касаются только части кода

**Заполняет:** `.claude/rules/*.md` и критерий «что туда»
**Спрашивать:** всегда
**Зачем:** свод обязан остаться под 200 строк, иначе правило теряется в шуме.
Всё, что касается части кода, уходит в правила по путям и подгружается, когда
агент трогает эти пути.
**Плохой ответ:** вынести в правила по путям то, что касается всего проекта.
Оно не загрузится тогда, когда нужно, и станет невидимым.
**Источник:** задача З1.3.

### В1.5 Есть ли уже написанные материалы по проекту

**Заполняет:** `docs/sources/<slug>.md`
**Спрашивать:** всегда, в конце этапа
**Зачем:** типовой вход в конвейер. Бриф, PRD, README прошлой версии,
расшифровка встречи, конкурентный анализ — в них обычно есть ответы на
половину Э2 и куски Э3–Э4, и пересказывать это в интервью значит потерять
время и получить текст хуже исходного.
**Плохой ответ:** положить материал на место документа рамок. Источник лежит в
`docs/sources/`, помечается `origin` и больше не меняется; документы рамок
заполняются из него разбором с подтверждением (`ADR-0005`).
**Источник:** задача З1.6.
