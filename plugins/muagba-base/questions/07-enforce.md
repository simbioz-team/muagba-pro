# Э7. Принудительные рамки — вопросы

Здесь текст превращается в механику. Вопросы выведены из задач `pipeline.md`.

### В7.1 Какие команды агент выполняет в этом проекте постоянно

**Заполняет:** `.claude/settings.json` → `allow`
**Спрашивать:** всегда
**Зачем:** лишние подтверждения — главная причина, по которой права в итоге
отключают целиком. Разрешить рутину значит сохранить работоспособность
запретов.
**Плохой ответ:** разрешить `Bash` целиком. Правила пишутся по шаблону
команды: `Bash(npm run *)`, `Bash(git status)`.
Отдельно: если решение по команде отдаётся хуку (`permissionDecision:
allow`), её **не должно быть в `ask`** — ask- и deny-правила Claude Code
проверяет независимо от хука, и allow хука их не перебивает. Каркас держит
`Bash(git push *)` в `ask`; образец `.claude/hooks/branch_policy.py`
работает, только если эту строку убрать.
**Источник:** задача З7.1; про allow и ask — проект narta.

### В7.2 Что в этом проекте нельзя выполнять никогда

**Заполняет:** `.claude/settings.json` → `deny`
**Спрашивать:** всегда
**Зачем:** база закрывает разрушительное — принудительный пуш, жёсткий сброс,
рекурсивное удаление от корня. Проектное знает только команда: прод-миграции,
обращения к боевым данным, деплой.
**Плохой ответ:** правило на запись через `Write(...)` или `Glob(...)`. Такие
правила принимаются, но никогда не консультируются — работает только
`Edit(...)` и `Read(...)`.
**Источник:** задача З7.1.

### В7.3 Какие файлы правит только человек

**Заполняет:** `.claude/protected-paths.txt`
**Спрашивать:** всегда
**Зачем:** база уже защищает секреты, lock-файлы, документы рамок и
`docs/sources/`. Вопрос про остальное: сгенерированный код, схемы миграций,
конфигурация прода.
**Плохой ответ:** защитить весь `docs/`. Тогда агент не сможет вести ADR и
записывать выученное, а это его работа.
**Источник:** задача З7.2.

### В7.4 Потеря чего ломает работу после сжатия контекста

**Заполняет:** `.claude/invariants.md`
**Спрашивать:** всегда
**Зачем:** после компакции агент теряет разговор, но не файлы. Короткий список
критичного возвращается в контекст хуком.
**Плохой ответ:** пересказ конституции. Инварианты — это пять–десять строк,
без которых агент начнёт делать неправильно немедленно: имя основной ветки,
запрет на прямой пуш, ключевое правило хранения, команда проверки.
**Источник:** задача З7.4.

### В7.5 Что из помеченного «машинно» на Э3 осталось без механики

**Заполняет:** подтверждение `const.enforced`
**Спрашивать:** всегда, в конце этапа
**Зачем:** пометка «машинно» была обещанием. Здесь оно либо выполняется хуком
или правом, либо принцип переводится в «только совет». Третьего нет.
**Плохой ответ:** оставить как есть. Проба `const.enforced` не подтвердится, и
Э3 останется открытым.
**Зависит от:** В3.3.
**Источник:** задачи З3.2, З7.3.

### В7.6 Подписывается ли агент соавтором в коммитах и PR

**Заполняет:** `.claude/settings.json` → `attribution`
**Спрашивать:** всегда
**Варианты:** не подписывается — `commit` и `pr` пустые строки,
`sessionUrl: false`; подписывается как по умолчанию; своя строка.
**Зачем:** Claude Code по умолчанию ставит `Co-Authored-By` в каждый коммит и
строку в описание PR. Многие этого не хотят и узнают о подписи, когда она уже
в истории, — а история переписывается дорого. Спросить надо **человека**, а
не решить за него: ни один из ответов не правильнее другого.
Второй вопрос — чьё это решение. Правило для всей команды — в
`settings.json`; личное предпочтение одного разработчика — в
`.claude/settings.local.json`, она в `.gitignore`. Если в проекте работают и
другие агенты, продублировать решение строкой в `AGENTS.md`: настройка Claude
Code для них ничего не значит.
**Плохой ответ:** промолчать, оставив умолчание. Проба `enforce.attribution`
не отличает «хочу подпись» от «не спрашивали», поэтому и требует записи.
Устаревший ключ `includeCoAuthoredBy` засчитывается, но писать надо
`attribution`.
**Источник:** автор базы — пожелание не видеть агента соавтором.
