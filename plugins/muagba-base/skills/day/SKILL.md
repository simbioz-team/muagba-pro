# Утро: снять ночь

1. **Сними ночь сам** — из корня проекта, именно так, относительным путём
   (разрешение проекта написано на `./.claude/night-switch`, абсолютный
   путь с ним не совпадёт, и ночью контролёр откажет):

   ```bash
   ./.claude/night-switch off
   ```

   Она закрывает пометку ночи: хуки сразу перестают отказывать, вопросы
   снова идут к человеку. Ночные разрешения контролёра держит сам процесс,
   запущенный лаунчером, — они уходят только перезапуском. **Передай
   человеку строку перезапуска из ответа дословно** (`/exit`, затем
   `claude --resume <id>`). Не говори «ночь выключена», пока он не
   перезапустил сессию: разрешения ещё ночные.

   Ответ назвал другие ночные сессии — перечисли их человеку и спроси,
   снять ли ночь у всех. Да — `./.claude/night-switch off --all`, и строки
   перезапуска каждой.

   Нет `.claude/night-switch` (проект ещё не получил его от базы) — дай
   человеку строку и попроси выполнить её с `!` впереди:

   ```
   ! python3 "${CLAUDE_PLUGIN_ROOT}/scripts/night_switch.py" off
   ```
2. Режим `auto` человек оставляет или выключает сам (Shift+Tab).
3. Проведи утренний разбор по `/muagba-base:night-report`.
