# Утро: выключить ночь

1. **Выключи ночь сам** — из корня проекта, именно так — относительным путём (разрешение
   проекта написано на `./.claude/night-switch`, абсолютный путь с ним не
   совпадёт, и ночью контролёр откажет):

   ```bash
   ./.claude/night-switch off
   ```

   Она снимает пометку ночи этой сессии и убирает из `~/.claude/settings.json`
   ровно то, что добавила ночь, — когда ночных сессий больше не осталось.
   Пока правила на месте, их видят все сессии в режиме `auto`.

   Ответ назвал другие ночные сессии (ночью работали несколько сессий
   проекта) — перечисли их человеку и спроси, снять ли ночь у всех. Да —
   `./.claude/night-switch off --all`. Ночная сессия, которую не
   выключили, держит правила в настройках человека до утра следующего дня.

   Нет `.claude/night-switch` (проект ещё не получил его от базы) — дай
   человеку строку и попроси выполнить её с `!` впереди:

   ```
   ! python3 "${CLAUDE_PLUGIN_ROOT}/scripts/night_switch.py" off
   ```
2. Режим `auto` человек оставляет или выключает сам (Shift+Tab).
3. Проведи утренний разбор по `/muagba-base:night-report`.
