# Ночь в этой сессии

Ночь — эта же сессия, переключённая на ночь (`ADR-0016`): контролёр —
режим `auto` Claude Code, правила для него — ночные правила проекта плюс
утверждённое на сегодня, а вопрос человеку становится отказом с записью в
`.claude/logs/morning.md`. Claude Code подхватывает правила на ходу, ничего
перезапускать не нужно.

1. **Найди ночные файлы проекта:**

   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/scripts/night_locate.py"
   ```

   Если `launcher` — `null`, ночной режим в проекте не настроен. Скажи
   человеку взять `.claude/night/` из каркаса muagba-pro (вопрос В9.11) и
   остановись.
2. **Подготовка.** Если `approved_today` — `false`, проведи её по
   `/muagba-base:night-prep` прямо здесь. Утверждённое запиши в файл из
   поля `approved`.
3. **Подтверждение.** Покажи утверждённое: задачи, разрешения, каждое ⚠
   отдельно. Спроси одним вопросом: «Включить ночь с этими разрешениями?»
   Без явного «да» дальше не идёт.
4. **Включение — делает человек.** Дай ему одну строку и попроси
   выполнить её в этой сессии с `!` впереди:

   ```
   ! python3 "${CLAUDE_PLUGIN_ROOT}/scripts/night_switch.py" on --session <id этой сессии>
   ```

   Id возьми из `echo $CLAUDE_CODE_SESSION_ID` и подставь в строку. Сам её
   не выполняй: она дописывает правила в настройки человека, а правка своих
   прав агенту запрещена.

   Затем попроси переключить режим на `auto` (Shift+Tab), если он ещё не
   `auto`.
5. **Проверь**, что ночь включилась:
   `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/night_switch.py" status`. Затем
   скажи человеку: ночь идёт в этом терминале, можно уходить; утром —
   `/muagba-base:day`.
6. **Работай:** задачи из `approved` по порядку. Упёрся в человека —
   хук откажет и запишет. Обратимое реши по умолчанию со «Спросить: да»,
   необратимое отложи и бери следующую независимую задачу. Не останавливай
   ночь вопросом: задать его некому.
