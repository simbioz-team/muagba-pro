# Ночь этой сессии

Ночь (`ADR-0016`) — эта же сессия, перезапущенная лаунчером
`.claude/claude-night`: контролёр — режим `auto` Claude Code, правила для
него — ночные правила проекта плюс утверждённое на сегодня, а вопрос
человеку становится отказом с записью в `.claude/logs/morning.md`. Правила
лаунчер передаёт только этому процессу — другие сессии человека ночи не
получают. Поэтому без перезапуска ночь не начинается.

1. **Найди ночные файлы проекта:**

   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/scripts/night_locate.py"
   ```

   Если `launcher` — `null`, ночной режим в проекте не настроен. Скажи
   человеку взять `.claude/night/` из каркаса muagba-pro (вопрос В9.11) и
   остановись.
2. **Подготовка.** Если сегодня её у этой сессии не было, проведи её по
   `/muagba-base:night-prep` прямо здесь, без её последнего шага — как
   стартует ночь, скажет шаг 4 ниже. Запомни, в какой файл записано
   утверждённое: его путь пойдёт лаунчеру. Была — возьми файл, который она
   записала (`approved` из шага 1, если не знаешь другого).
3. **Подтверждение.** Покажи утверждённое: задачи, разрешения, каждое ⚠
   отдельно. Спроси одним вопросом: «Начать ночь с этими разрешениями?»
   Без явного «да» дальше не идёт.
4. **Строки запуска.** После «да» — из корня проекта, именно так,
   относительным путём (разрешение проекта написано на
   `./.claude/night-switch`, абсолютный путь с ним не совпадёт):

   ```bash
   ./.claude/night-switch on --approved <абсолютный путь файла утверждённого>
   ```

   Она проверит, что утверждённое сегодняшнее, и напечатает две строки:
   `/exit` и запуск лаунчера с `--resume` этой сессии. **Передай их
   человеку дословно, последними строками ответа**, и больше ничего не
   делай: ночь начнётся, когда он перезапустит сессию. Сам лаунчер не
   запускай — ни через Bash, ни через `!`: вторая копия этой же сессии
   рядом с открытой — две сессии с одной историей.

   Нет `.claude/night-switch` (проект ещё не получил его от базы) — дай
   человеку строку и попроси выполнить её с `!` впереди:

   ```
   ! python3 "${CLAUDE_PLUGIN_ROOT}/scripts/night_switch.py" on --session <id этой сессии> --approved <путь>
   ```

Ночью сессия начнёт с поручения лаунчера: задачи из утверждённого по
порядку. Упёрлась в человека — хук откажет и запишет. Обратимое реши по
умолчанию со «Спросить: да», необратимое отложи и бери следующую
независимую задачу. Утром — `/muagba-base:day`.
