# Ночной прогон из сессии

Ночь — фоновая сессия Claude в режиме `auto` с ночными правилами
(`ADR-0016`). Её запускает лаунчер проекта `.claude/claude-night`. Эта
команда находит его, готовит ночь вместе с человеком и запускает.

1. **Найди лаунчер:**

   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/scripts/night_locate.py"
   ```

   Если `launcher` — `null`, ночной режим в проекте не настроен. Скажи
   человеку, что нужно взять `.claude/night/` и `.claude/claude-night` из
   каркаса muagba-pro (вопрос В9.11, проба `cycle.night`), и остановись.
   Ставит их человек: файлы защищены.
2. **Подготовка.** Если `approved_today` — `false`, проведи подготовку по
   `/muagba-base:night-prep` прямо здесь. Утверждённое запиши в файл из
   поля `approved` — он лежит рядом с найденным лаунчером, а не
   обязательно в твоём каталоге.
3. **Подтверждение.** Покажи человеку утверждённое из `approved`: задачи,
   разрешения, каждое ⚠ отдельно. Спроси одним вопросом: «Запустить ночь
   с этими разрешениями?» Без явного «да» — не запускай.
4. **Запуск:**

   ```bash
   bash "<launcher>" --yes --bg --resume "$CLAUDE_CODE_SESSION_ID"
   ```

   Ночь продолжит эту сессию в фоне. Claude Code запустит копию, потому
   что эта ещё открыта.

   Если запуск отклонён — правами или контролёром, — дай человеку ту же
   строку с `!` впереди: запуск ночи — его действие, и он может сделать
   его сам.
5. **Скажи человеку**, последним абзацем и крупно:
   - ночь запущена в фоне, её id — из вывода. Смотреть:
     `claude agents`, `claude attach <id>`;
   - **эту сессию закройте** (`/exit`), иначе будет два координатора, и
     дневной будет отвечать вопросами там, где ночной откажет;
   - утром: `claude attach <id>` и `/muagba-base:night-report`.

Права на ночь даёт человек: эта команда только проводит подготовку и
запускает то, что он утвердил.
