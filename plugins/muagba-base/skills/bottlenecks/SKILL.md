# Очереди конвейера

Сводка строится по стенограмме координатора: поручения агентам, их
завершения, продолжения и слияния уже записаны. Новых хуков и правки
настроек не нужно.

1. Определи окно этапа: начало — первое поручение этапа, конец — слияние
   последней задачи или сейчас. Время — UTC.
2. Запусти:

   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/scripts/pipeline_queues.py" \
     --since <начало> [--until <конец>] --ci --csv .claude/logs/pipeline
   ```

   Ключ задачи по умолчанию — `T\d{3}` в описании или тексте поручения.
   Если в проекте нумерация другая, передай свой шаблон через `--task-re`.
   Без сети или без `gh` убери `--ci`: тогда не будет очереди к раннеру.
3. Покажи человеку:
   - **самые долгие очереди** и чем в это время был занят координатор.
     Если в колонке есть `AskUserQuestion`, значит ждали владельца, а не
     координатора. Это решается сбором вопросов до ухода человека
     (`ADR-0014`), а не ускорением агентов;
   - **звенья с наибольшей суммой очереди**: какое звено конвейера в узком
     месте;
   - **простой**: отрезки, когда не работал ни один агент;
   - **CI**: очередь к раннеру против времени самой сборки. Если очередь
     сопоставима со сборкой, раннер — узкое место.
4. Строку итогов допиши в журнал этапа, рядом со статистикой проверок.
   Сравнивать этапы можно только между собой и с оговоркой: задачи
   разные.

Чего сводка не видит: работу внутри одного хода координатора и
поручения без ключа задачи. Такие поручения считаются в работе по
ролям, но не попадают в цепочки задач.
