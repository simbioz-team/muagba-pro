# Утро после ночного прогона

1. Запусти:

   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/scripts/night_report.py"
   ```

   По умолчанию берутся последние 16 часов. Начало ночи можно задать
   явно: `--since <ISO>`.
2. Покажи человеку, в таком порядке:
   - **вопросы и отложенное** из `.claude/logs/morning.md`. Это то, на чём
     задачи встали. Ответы записывай в источник (`ADR-0014`);
   - **отказы контролёра.** Каждый отказ — это либо правильно
     остановленное, либо дыра в подготовке: разрешение, которое стоило
     утвердить вечером. Второе — строка в следующую подготовку;
   - **что сделано:** слияния, задачи, красные гейты.
3. Когда вопросы разобраны, перенеси `morning.md` в журнал этапа и очисти
   его. Новая ночь начинается с пустого списка.

Решения контролёра «разрешить» в стенограмме не видны: видны только
отказы. Аудит одобренного — по журналу команд, если он нужен.
